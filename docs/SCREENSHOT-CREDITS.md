# GrainAgent showcase images

The README and quick-start PDF images are **retouched illustrations based on
the running GrainAgent 1.0.1 Build 29 interface**, captured on macOS 26. They are not
unaltered screen captures or image-quality benchmarks.

## Photography

**Photographs © 2026 Richard Jin**, supplied by the photographer for the
GrainAgent public showcase:

- `DSC00659.ARW`: the landscape photograph shown in Simple mode, using
  Fujifilm Velvia 100.
- `DSC00665.ARW`: the portrait photograph inspected with the comparison control
  in Pro mode, using Fujifilm Pro 400H and Fujifilm Crystal Archive Type II.

The photographs remain the photographer’s work. Permission to display them in
this showcase does not relicense the photographs under the repository’s code
licence. No raw photo files, camera metadata or original downloads are published.

## Production

Both base images were captured from the accepted application with the supplied
photographs loaded. OpenAI image generation was used for presentation cleanup:
replace the macOS screen-sharing overlay with normal traffic-light controls,
remove the pointer and focus highlight, and reduce duplicate reflections behind
the glass panels. Fine image detail in these retouched illustrations may differ
from the live app; use the app itself to evaluate rendering.

The software, processing engine, original RAW files and accepted installation
package were used as the basis of the illustrations. The illustrations appear
in the README and the PDF included beside the app.
