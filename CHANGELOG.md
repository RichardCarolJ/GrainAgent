# GrainAgent version history

See the [product overview](README.md) for Simple and Pro workspaces, per-photo
edits and batch export, and [attribution](NOTICE.md) for the upstream projects.

## 1.0.1 · Build 29 · 2026-11-07

- Fixed a crash when switching between Simple and Pro on macOS 14 and 15.
- The release passed testing on Macs running macOS 14 and 15.
- The Mac download includes GrainAgent and an illustrated quick-start guide in
  English and Simplified Chinese.

## 1.0.1 · Build 28

- Extended Apple Silicon support to macOS 14.
- Rebuilt both Metal libraries for macOS 14 from the existing shader sources.
  The release retains the existing film and paper data and imaging algorithms.

## 1.0.1 · Build 27

- Corrected the app icon's rounded corners and margins on macOS 15.
- Verified the result on an M1 MacBook Air running macOS 15.

## 1.0.1 · Build 26

- Added support for macOS 15 on Apple Silicon.
- Pro mode uses system translucent materials on macOS 15 and native Liquid
  Glass on macOS 26 or later.

## 1.0.1 · Build 25

- Added English, Simplified Chinese, French, and Spanish throughout the app.
- The app follows the system language at first launch and uses English when
  that language is unavailable. You can change the language in Settings.
